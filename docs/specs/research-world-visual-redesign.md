## Problem Statement

首页「研究世界」演示区块呈现质量不足：图谱是约 300 个均匀灰点的散布网络，无层级、无色彩结构，像随机噪声；镜头拉近的章节里背景整层被 CSS blur 模糊，画面浑浊、标签在画布边缘裁切；章节切换只有图层不透明度交叉淡入加右侧文字瞬时替换，路线无描线编排，关键节点（Gap、候选方法）出场无强调；进度条无章节刻度，控件样式与整站脱节。

## Solution

在保留既有架构与全部不变量的前提下重做视觉语言与章节编排：

- **图谱视觉**：群落引入色相锚点（统一冷墨色系）+ 径向渐变光晕层；背景节点按到群落中心的归一化距离分三级（tier 1–3），尺寸与不透明度（alpha）烘焙进数据；前景故事节点满强度墨色；区域色块重绘为有机形状 + 垂直渐变 + 字距标签。
- **景深表达**：删除 CSS blur 整层模糊，非聚焦表达改为层不透明度（既有 pose 字段）+ 烘焙 alpha 的自然衰减，缩放画面保持锐利。
- **章节编排**：路线保留描线（stroke-dashoffset）；论文图标与文献脉络停点按层值错落（stagger）渐显；探索路径停点随描线到达渐显并在探索后持久（只增不减语义）；Gap / 候选保留 pop 并增加光晕与慢转虚环；想法标记呼吸。
- **叙述与控件**：讲解文字成对过渡（旧文字淡出上移、新文字淡入下移）；「要点」绿色胶囊强调；进度条增加 13 个可点击章节刻度点；控件与整站圆角胶囊 + ring 语言对齐。
- **入场**：背景节点按到世界中心距离涟漪式点亮（一次性 CSS 动画，`backwards` 填充，减少动态时禁用）。

## Invariants（红线）

- `sampleStory(progress)` 与场景渲染器保持纯函数：同一 progress 恒等输出，反向回看与正向一致；所有渐显都是 pose 值的连续函数，**任何元素不得二值弹出**。
- 语义配色保留：金色=想法、琥珀=缺口/候选、紫=边界、青绿=迁移；群落色板不占用语义色。
- 演示免责声明、aria 标注、sr-only live region、完整文字讲解、减少动态分支、小屏模式、键盘导航全部保留。

## Testing

- `scripts/test-research-story.mjs`（prebuild）：世界数据合法性（色板、tier、alpha、语义色隔离）、姿态插值纯度/可逆性/边界、层可见性相位、stagger 与停点渐显的连续性/持久性/确定性、渲染器复位。
- `scripts/smoke-research-story.mjs`（`npm run test:visual`，独立不进 prebuild）：Playwright 逐 13 章节 × 桌面/移动宽度截图到 `smoke-artifacts/`，断言画布非空白、无水平溢出、无页面错误（曾据此抓出并修复 `Math.hypot` 引起的水合不一致）。
- 浏览器走查：全部 13 章 × 双宽度截图逐张核对（层级、无裁切、不发糊、编排连贯）。
